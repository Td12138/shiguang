# 选题方案对比（供与队友讨论）

> 结论先行：**推荐方案 1「见字如面」**。它是唯一能把已有资产变成评分表六项 AI 子项全覆盖的方案，创新性天花板最高；代价是工期最紧，必须按本文的 MVP 切法砍功能。

## 1. 评分表倒推出的硬指标

省赛评分 35% 给 AI 技术深度，且拆成六个单独打分的子项。任何一项空缺 = 直接丢分：

| 子项 | 分值 | 必须有的证据 |
|---|---|---|
| 大模型集成 | 8 | 结构化输出 + 校验重试 + Prompt 版本化 |
| Agent/工作流 | 8 | 规划 → 工具调用 → 自检 → 产出的显式状态机，可回放 |
| RAG | 6 | 混合检索 + **引用回链原文** |
| 多模态 | 5 | ≥2 种模态真实参与主流程（不是装饰） |
| AI 安全可控 | 4 | 置信度可视化、内容过滤、兜底降级、免责声明 |
| MCP/工具 | 4 | Function Calling 注册表 + 一个真 MCP Server |

## 3. 三个候选方案

### 方案 1「见字如面」· 家书数字化与笔迹续写（文化共创）

**一句话**：拍一张老照片或手写家书，AI 转写、考据、讲清它背后的年代与风俗，再用**同一笔迹**写一封回信。

主流程：拍照/上传 → VLM 转写 + PP-OCR 双引擎交叉校验（不一致处高亮，人一键校对）→ 实体抽取 → 民俗/地方志知识库 RAG（每条结论带引用角标，可回链原文）→ 生成「这一页背后的故事」→ 笔迹渲染回信（真迹字形库）→ 家族时间轴归档。

| 项 | 评估 |
|---|---|
| 资产复用 | 5 项（OCR、笔迹、字形库、检索、Agent 结构） |
| 评分覆盖 | 6/6 全覆盖；多模态=图像理解+手写图生成+语音朗读，三项都进主流程 |
| 创新性 | 高。「笔迹续写」是评委没见过的交互；选题落在代际记忆，社会价值天然成立 |
| 工期 | 高。3 天需并行 4 条线 |
| 风险 | 手写识别准确率（用双引擎一致性 + 人工校对化解，反而是安全得分点）；笔迹合成的伦理边界 |
| 安全设计 | 仅本人授权 + 生成件强制水印 + 禁止导出无水印版 → 直接写成 AI 安全 4 分的论据 |

### 方案 2「账单里的碳」· 家庭碳账本（绿色生活）

拍照/导入电费单、加油票、外卖单 → 识别进可编辑表单 → 碳排因子库 RAG 核算（每个数字带出处）→ Agent 规划周度减排 → 「减排沙盘」拖滑块看 2030 累计减排。

| 项 | 评估 |
|---|---|
| 资产复用 | 2 项（OCR、检索） |
| 评分覆盖 | 5/6：多模态只有票据一种，偏弱 |
| 创新性 | 中。碳账本类产品已有先例，靠交互沙盘拉分 |
| 工期 | 中。数据可信度要自己搭因子表，工作量在数据不在代码 |
| 风险 | 数值准确性会被追问；社会价值高、技术亮点平庸 |

### 方案 3「资料即懂」· 纸质资料 → 结构化知识卡（智慧教育）

拍照书页/讲义 → 分栏分块 OCR → 结构化抽取 → 知识卡 + 自测题。

| 项 | 评估 |
|---|---|
| 资产复用 | 6 项最高 |
| 评分覆盖 | 5/6 |
| 创新性 | 低。与你已有作品同源，**有原创性质疑风险**（往届作品不得重复参赛） |
| 工期 | 低 |
| 风险 | 性价比最差：省力但拿不到创新分 |

### 一句话比较

| | 复用度 | 六项覆盖 | 创新天花板 | 工期风险 | 建议 |
|---|---|---|---|---|---|

## 4. 方案 1 的 72 小时拆解

| 时段 | 交付 | 完成标准（可验证） |
|---|---|---|
| 11-15 晚 | 仓库 + 脚手架 + 双引擎转写闭环 | 上传一张图，返回转写文本 + 两引擎差异高亮；`pnpm build` 通过 |
| 11-16 上午 | 笔迹渲染服务 | 输入一段话，返回 PNG（字形库缺字自动兜底并列出缺字） |
| 11-16 下午 | RAG 知识库 + 引用回链 | 20–50 条公开语料；回答点角标能定位到原文段落 |
| 11-16 晚 | Agent 流水线 | trace 面板可见 4 步状态；引用自检失败自动重生成 1 次 |
| 11-17 上午 | 时间轴 + 家族空间 + 安全层 | 水印、过滤、兜底、免责声明全在；断网时有降级文案 |
| 11-17 下午 | 前端打磨 + 部署 | 首屏 < 2 s（本地）；空态/错误/加载全覆盖；公网可访问 |
| 11-17 晚 | 技术文档初稿 | ≤30 页，含架构图/评分对照/数据来源 |
| 11-18 上午 | 视频 + 定稿 + 提交 | 5–8 min 1080p；仓库 public；已点提交 |

**MVP 砍线**（时间不够时按顺序砍）：语音朗读 → 家族多人协作 → 时间轴可视化 → 只保留「转写→考据→笔迹回信」一条主线。

## 5. 需要拍板的 5 件事

1. **选题**：方案 1 / 2 / 3，或你们自己的方向（给我一句话场景 + 目标用户即可）。
2. **分工**：团队赛 1–3 人。若只有你一人，视频讲解与文档会挤占开发时间，建议至少拉 1 人负责录制与文档。
3. **模型 key**：智谱开放平台注册 5 分钟，`glm-4-flash`（文本）+ `glm-4v-flash`（视觉）有免费额度，一套 key 覆盖 LLM 与多模态。没有 key 就只能 mock，35% 的 AI 深度直接失分。
4. **手写素材**：演示是否使用 `outputs/handwriting/glyphs` 里的真迹字形库？建议只做「本人授权」演示样例，并在文档里写明授权与防伪设计。
5. **在线 Demo**：是否花 2 小时部署到 tedserver 并开公网入口（评分表里是可选加分项）。
