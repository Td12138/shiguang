# 06 数据来源、口径与合规

> 一句话：三类数据（保质期 / 碳排因子 / 价格）都是**公开资料 + 人工校准的估算值**，口径写在页面上，误差写清楚，不当成事实卖。

## 1. 数据分层

| 层 | 文件 | 内容 | 谁维护 |
|---|---|---|---|
| 食材基础表 | `apps/server/app/data/items.json` | `shelf_life_days` / `carbon_kg_per_kg` / `price_per_kg` / `avg_grams` / `storage_tip` / `unit` | 人工定口径，AI 填表 |
| 菜谱语料 | `apps/server/app/data/recipes.json` | 标题、配料、步骤、时长、份数、难度 | 自写/改写，逐条注明来源 |
| 保存技巧 | `apps/server/app/data/tips.md` | 分条，供 RAG 引用 `tip:<n>` | 同上 |
| 计算常量 | `apps/server/app/domain/stats.py` 顶部全大写常量 | 车辆 km 碳排、树木年吸收量 | 单一来源，文档与代码同值 |

## 2. 三类数据：来源与口径

### 2.1 保质期 `shelf_life_days`

| 项 | 说明 |
|---|---|
| 口径 | **家用冷藏建议食用期**：4 ℃ 冰箱、未开封/未切开的完整状态、从购买当天算起 |
| 不等于 | GB 7718 里那个法定「保质期」，也不是「过这一天就中毒」 |
| 来源 | ①USDA FoodKeeper（美国政府公开数据，公共领域）的冷藏天数区间 ②国内常见冷藏经验值（叶菜 3–5 天、根茎 7–14 天、生鲜肉 2–3 天） ③自购实测抽查 |
| 取值 | 取来源区间的**中位数**，向下取整 |
| 误差 | ±1–2 天，随冰箱实际温度、摆放位置、是否带水变化 |
| 处理 | 切开/清洗过的食材，用户在确认表单里手动缩短到期日（不自动推断，避免假精确） |

### 2.2 碳排因子 `carbon_kg_per_kg`

| 项 | 说明 |
|---|---|
| 口径 | kg CO₂e / kg **可食部**，覆盖「生产 → 加工 → 运输 → 零售」这一段（farm-to-retail gate），**不含**家庭冷藏耗电与烹饪燃气 |
| 来源 | ①Poore & Nemecek, *Science* 360 (2018) 全球食物生命周期均值 ②Our World in Data「Food: greenhouse gas emissions across the supply chain」可下载数据集（CC BY） ③国内食物系统温室气体排放相关公开研究用于本地化修正 |
| 取值 | 同一食材多个来源取均值，保留两位小数；牛肉/羊肉等反刍类显著高于植物类（这是文献里的稳定结论，不是我们编的） |
| 误差 | **±30%**（文献区间跨度本身就大，地域与季节差异更大） |
| 用途边界 | 只用于行为反馈与趋势对比，**不做碳核查、不做碳交易、不做企业披露** |

### 2.3 价格 `price_per_kg`

| 项 | 说明 |
|---|---|
| 口径 | 本地区连锁超市 + 生鲜电商**公开挂牌价**，2026 年 11 月抽样，取中位数 |
| 不含 | 促销价、会员价、配送费、损耗折价 |
| 误差 | ±20%（地区、季节、品类波动） |
| 用途边界 | 只算「大概省了多少钱」，不代表实际支付金额 |
| 合规 | 只记录公开挂牌数字，**不抓取、不复刻**任何 App 的数据库与接口 |

### 2.4 克重 `avg_grams` 与等效换算

| 常量 | 值 | 来源 |
|---|---|---|
| 单件平均可食部重量 | 逐食材填写（如一颗西兰花 300 g） | 厨房秤实测 10 次取中位数，去皮去籽 |
| 汽油乘用车 | **0.137 kg CO₂e / km** | 公开因子区间 0.12–0.20 取中低位 |
| 一棵树年吸收 | **16 kg CO₂e / 年** | 公开区间 10–20 取中位 |
| 换算公式 | `car_km = carbon_saved_kg / 0.137`；`trees_days = carbon_saved_kg × 365 / 16` | 代码与本文同值，改一处必须改两处 |

## 3. 「估算值」的边界（对外必须说清的四条）

| # | 边界 | 说法 |
|---|---|---|
| 1 | 保质期是建议，不是安全线 | 「能不能吃」以感官判断为准 |
| 2 | 碳当量是量级估算 | 误差 ±30%，用于比较与激励，不用于核算 |
| 3 | 价格是抽样中位数 | 不代表你实际花了多少钱 |
| 4 | 份量与克重靠用户填写 + 平均单重推算 | 误差 ±15% |

## 5. 照片与隐私承诺

| 项 | 承诺 |
|---|---|
| 演示素材 | 视频与截图中的冰箱照片**全部自摄**（或使用明确授权的图库），不使用任何用户真实照片 |
| 存储 | 上传图片只写入本机 `apps/server/data/uploads/`，随 `data/` 一起被 `.gitignore` 排除，不进公开仓库 |
| 训练 | 图片**不进入任何训练集**，不用于微调，不做二次分发 |
| 账号 | 无账号体系、无登录、无手机号/邮箱采集，因此不持有任何个人身份信息 |
| 统计 | 无第三方统计 SDK、无埋点、无广告脚本 |
| 出网披露 | `provider=mock` 时**不出网**；`provider=zhipu/dashscope` 时，图片与文本会发送至对应模型服务商的 API。这一点必须写进 README，不能含糊 |
| 拍摄注意 | 录屏前清空冰箱门上的快递单、外卖小票等含姓名电话的物件 |
